Política de Privacidade

Aplicativo: Scheduler (com.anewworld.scheduler)
Última atualização: 8 de setembro de 2026

Esta Política de Privacidade descreve como o aplicativo Scheduler trata informações quando você o utiliza. O Scheduler é um gerenciador de tarefas que funciona principalmente no seu dispositivo.

2. Quais dados são tratados

O Scheduler permite que você cadastre tarefas com informações como:

  • título da tarefa;
  • descrição;
  • data;
  • status (pendente, concluída ou excluída).

Esses dados são inseridos por você e armazenados localmente no seu dispositivo, por meio de banco de dados SQLite.

3. O que o app NÃO faz

  • não cria conta de usuário;
  • não solicita login;
  • não coleta dados de localização, câmera, contatos ou microfone;
  • não envia suas tarefas para servidores nossos;
  • não utiliza serviços de publicidade;
  • não utiliza ferramentas de analytics de terceiros no app.

4. Como usamos os dados

Os dados das tarefas são usados apenas para fornecer as funcionalidades do app: criar, editar, concluir, excluir e visualizar o histórico de tarefas no próprio dispositivo.

5. Armazenamento e segurança

As informações ficam armazenadas localmente no dispositivo. A exclusão do aplicativo ou a limpeza dos dados do app pelo sistema operacional pode resultar na perda dessas informações. Recomendamos que você mantenha o dispositivo protegido com os recursos de segurança do próprio sistema (senha, biometria etc.).

6. Compartilhamento de dados

Não vendemos, alugamos nem compartilhamos os dados das suas tarefas com terceiros. Como o armazenamento é local, o conteúdo das tarefas não é transmitido por nós a servidores externos.

7. Dados de crianças

O Scheduler não é direcionado a crianças menores de 13 anos e não coleta intencionalmente dados pessoais de crianças.

8. Permissões

O aplicativo não depende de permissões sensíveis (como localização, câmera ou contatos) para funcionar.

9. Alterações nesta política

Podemos atualizar esta Política de Privacidade periodicamente. A data da “Última atualização” no topo desta página indica a versão vigente.
